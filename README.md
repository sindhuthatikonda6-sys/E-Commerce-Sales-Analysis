# E-Commerce Sales Analysis Dashboard

An interactive sales analysis dashboard created using Microsoft Excel to analyze e-commerce sales performance and identify useful business trends.

## Project Overview

This project analyzes 100 e-commerce transactions and presents the results through an Excel dashboard.

The dashboard helps understand sales performance across different categories, cities, payment methods, and months.

## Tools & Technologies

- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Data Visualization
- Dashboard Design

## Key Performance Indicators

- Total Sales: ₹2,81,893
- Total Orders: 100
- Total Quantity Sold: 307
- Average Order Value: ₹2,818.93

## Analysis Performed

- Sales by Category
- Sales by City
- Sales by Payment Method
- Monthly Sales Trend
